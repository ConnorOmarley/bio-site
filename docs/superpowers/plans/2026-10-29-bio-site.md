# Bio site estilo Coonexta Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Página única de link na bio, mobile-first, no estilo do Coonexta, para uma cabeleireira, com todos os dados em `config.js`.

**Architecture:** Site estático (sem servidor). `logic.js` guarda as funções puras (horários, link do WhatsApp, Pix), testadas com `node --test`. `app.js` lê `config.js` e monta a página e os modais. `style.css` usa variáveis de cor para trocar de nicho.

**Tech Stack:** HTML, CSS, JavaScript puro. Único código de terceiros: `qrcode-generator` (MIT, um arquivo, copiado para `vendor/`) para desenhar o QR Code. Testes com `node:test` (já vem no Node).

**Spec:** `docs/superpowers/specs/2026-10-29-bio-site-design.md`

## Global Constraints

- Idioma da página: português do Brasil. Moeda: `R$ 150,00`. Data: "quarta-feira, 12 de agosto".
- Sem servidor, sem banco de dados, sem login (isso é a Etapa 2).
- Nenhuma senha, chave ou dado real no código: `config.js` começa com dados de exemplo.
- Horários de 15 em 15 minutos; só entram horários em que o serviço termina até o fim do expediente.
- Layout pensado para 375px de largura; sem rolagem horizontal.
- Não fazer commit (o usuário pede quando quiser; a pasta não é um repositório git).

## Review Focus

- Hoje, depois do fim do expediente (ou todos os horários já passaram): o dia não deve oferecer horários.
- Serviço sem preço (como "Fibra de Vidro" no Coonexta): mostrar "a combinar", sem `R$ NaN`.
- Nome com acento, emoji ou mais de 25 caracteres: o Pix deve cortar e remover acentos; o WhatsApp deve codificar corretamente.
- Valor do Pix vazio, zero ou com vírgula ("50,00"): recusar vazio/zero e aceitar vírgula.
- Telefone digitado com parênteses, espaços e traço: a mensagem e o link devem funcionar; telefone da profissional só com dígitos e DDI 55.
- Imagem que não carrega (arquivo faltando): a página não deve quebrar.

### Task 1: Lógica pura (horários, WhatsApp, Pix)

**Files:**
- Create: `logic.js`, `tests/logic.test.js`

**Interfaces:**
- Produces (exportadas via `module.exports` no Node e `window.Logic` no navegador):
  - `crc16(text: string): string` — CRC-16/CCITT-FALSE, 4 hex maiúsculos.
  - `buildPixPayload({ key: string, name: string, city: string, amount: number }): string` — BR Code estático; `name` até 25 e `city` até 15 caracteres, maiúsculos e sem acento; termina em `6304` + CRC.
  - `generateSlots({ start: string, end: string }, stepMin: number, durationMin: number, now?: Date, day?: Date): string[]` — ex.: `["08:00","08:15",...]`; se `day` for hoje, remove horários que já passaram.
  - `isOpenDay(date: Date, openWeekdays: number[]): boolean` — 0 = domingo.
  - `formatPrice(value: number | null): string` — `"R$ 150,00"` ou `"a combinar"` quando for `null`.
  - `buildWhatsAppUrl(phone: string, b: { service: string, date: Date, time: string, name: string, clientPhone: string, notes: string }): string` — `https://wa.me/<dígitos>?text=<texto codificado>`.

- [ ] **Step 1: Escrever os testes que falham** em `tests/logic.test.js`: `crc16("123456789") === "29B1"`; `buildPixPayload` começa com `000201`, contém a chave, `5802BR`, valor `54045.00` para `amount: 5` e termina com CRC válido (recalcular o CRC do texto sem os 4 últimos caracteres); nome com acento e 40 letras sai sem acento e com 25; `generateSlots({start:"08:00",end:"10:00"},15,60)` retorna de `08:00` a `09:00`; `generateSlots` para hoje às 17:50 com expediente até 18:00 retorna `[]`; `formatPrice(150) === "R$ 150,00"` e `formatPrice(null) === "a combinar"`; `buildWhatsAppUrl("(11) 98888-7777", ...)` começa com `https://wa.me/5511988887777?text=` e o texto decodificado contém serviço, dia, hora e nome.
- [ ] **Step 2: Rodar `node --test tests/` e ver todos falharem** (funções não existem).
- [ ] **Step 3: Implementar as seis funções em `logic.js`** conforme as assinaturas acima. O Pix segue o padrão EMV do Banco Central (campos `00`, `26` com `br.gov.bcb.pix`, `52`, `53`=986, `54`, `58`, `59`, `60`, `62` com `***`, `63`).
- [ ] **Step 4: Rodar `node --test tests/` e ver todos passarem.**
